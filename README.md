# CRUD App – React

A simple and responsive **CRUD (Create, Read, Update, Delete) application** built using React.js. This project demonstrates how to perform CRUD operations with a REST API and manage application state using React.

## 🚀 Features

* Create new users
* Display users in a list/table
* Update existing user details
* Delete users
* Fetch data from REST API
* Form handling using React
* Responsive user interface
* Simple and clean design

## 🛠️ Technologies Used

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3
* Axios
* JSON Server
* Vite

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/anmolagrahari24/CRUD-APP-REACT.git
```

### 2. Go to the project directory

```bash
cd CRUD-APP-REACT
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start JSON Server

```bash
npx json-server --watch db.json --port 4000
```

### 5. Start React application

Open another terminal and run:

```bash
npm run dev
```

The application will run on:

```text
http://localhost:5173
```

## 🔄 CRUD Operations

### Create

Add a new user through the form and store the data using the REST API.

### Read

Fetch and display all users from the JSON Server.

### Update

Edit existing user information and update it through the API.

### Delete

Remove a user from the application and database.
